# Licence: GPL-2.0-only

This repo may carry local patches to `xone`, which is `GPL-2.0`. GPL-3.0 is
one-way incompatible with it, so the repo's original GPL-3.0 licence would have
made any such patch unshareable. Relicensed to `GPL-2.0-only` while it was free
to do so — sole author, one prior commit.

## Considered Options

- **GPL-3.0** (the original) — rejected: incompatible with `xone` and the kernel.
- **MIT** — genuinely viable, and the honest runner-up. Permissive-into-GPL means
  it blocks nothing. Rejected only for consistency: this is tooling for a
  GPL-2.0 ecosystem problem, and one licence avoids per-directory mixing if
  kernel-licensed material lands here.
- **GPL-2.0-only** — chosen.

## Consequences

- The GPLv2 text and the SPDX tag do different jobs: the licence text is
  identical for `-only` and `-or-later`, so the tag carries the whole
  distinction. This mirrors how the kernel does it.
- `docs/agents/*.md` is verbatim third-party text from `mattpocock/skills` (MIT).
  MIT is GPL-compatible so there is no conflict, but those files are not ours to
  relicense and should carry their own SPDX identifier.

## Note on the original rationale

This ADR was first written assuming the repo would produce an upstream `xpad`
patch. That is **not** the goal — the repo tracks making this pad playable, not
fixing `xpad` for everyone. The decision stands on the narrower `xone`-patch
ground above, but the upstreaming argument no longer applies and MIT would have
been a defensible choice.
